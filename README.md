## 📲 طريقة تثبيت تطبيق أندرويد (How to Install APK)

1. اضغط على رابط التحميل المباشر أعلاه لتحميل ملف `VYTRON-Manager-v0.4.1.apk`.
2. بعد اكتمال التنزيل، انقر على الملف لفتحه.
3. إذا ظهر لك تنبيه أمني من نظام أندرويد، اضغط على **الإعدادات (Settings)** وفعّل **السماح بتثبيت التطبيقات من هذا المصدر (Allow from this source)**.
4. اضغط على **تثبيت (Install)** ثم **فتح (Open)** واستمتع بالتطبيق!
