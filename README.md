## ⚡ أبرز مميزات VYTRON Manager

- 🚀 **تقسيم فائق للتحميل (Multi-Connection Turbo):** تقسيم الملف الواحد على ما يصل إلى 32 اتصالاً متزامناً للوصول لأقصى سرعة اتصال.
- ⏯️ **استئناف ذكي وفوري (Smart Resume):** إيقاف واستئناف التحميل في أي وقت دون تلف الملفات، حتى بعد انقطاع الإنترنت أو إعادة تشغيل الجهاز.
- 🌐 **تكامل كامل مع المتصفحات (Browser Integration):** التقاط الروابط تلقائياً من Chrome و Edge و Brave و Firefox مع أزرار التقاط عائمة فوق الفيديوهات.
- 🎬 **استخراج الفيديو وقوائم التشغيل (Video & Playlists):** تنزيل الفيديوهات بأعلى جودة (4K / 1080p / 60fps) وقوائم التشغيل الكاملة مع دمج الصوت والصورة تلقائياً.
- 🧲 **دعم التورنت المدمج (Built-in Torrent Engine):** تحميل ملفات وروابط التورنت والمغناطيس (Magnet) مباشرة داخل البرنامج دون الحاجة لبرامج إضافية.
- 🎨 **تصميم Midnight عصري وفخم:** واجهة داكنة مريحة للعين مع لمسات النيون الأزرق والبنفسجي، مع دعم كامل للوضع الفاتح والداكن و 8 لغات عالمية بينها العربية بالكامل.
- ⏰ **جدولة ذكية وقوائم انتظار (Scheduler & Queues):** جدولة التنزيلات ليلاً مع إمكانية إيقاف تشغيل الكمبيوتر تلقائياً فور اكتمال التنزيل.
- 🔒 **حماية البيانات وترحيل غير هدّام (Safe Data Migration):** الحفاظ التلقائي على سجل التنزيلات والإعدادات السابقة مع التحقق الصارم من سلامة الملفات.

## 🧩 طريقة تثبيت إضافة المتصفح (Browser Extension)

1. حمّل ملف الإضافة: [**VytronManager-Extension.zip**](https://github.com/aliwieii/VYTRON-Manager-Releases/releases/download/v1.0.0/VytronManager-Extension.zip) وفك الضغط عنه في مجلد دائم.
2. افتح متصفحك (Chrome أو Edge أو Brave) وتوجه إلى صفحة الإضافات (`chrome://extensions` أو `edge://extensions`).
3. فعّل **وضع المطور (Developer mode)** في الزاوية العلوية.
4. اضغط على زر **تحميل حزمة مفككة (Load unpacked)** واختر مجلد الإضافة.
5. مبروك! ستظهر أيقونة **VYTRON Manager** وستلتقط التنزيلات وأزرار الفيديو العائمة تلقائياً وبأقصى سرعة.
